# 酒馆多开 · Chat Tabs 1.3.0 试用版

从「魔术棒 → 多开聊天」创建独立窗口。各窗口保存自己的剧情、user 人设、当前预设参数、API 配置和密钥副本，使用原生酒馆聊天界面。关闭后可从已保存窗口列表继续。

**完整多开需要网页扩展与配套服务端组件。只通过“管理扩展”安装仓库，只能使用静音音频 / 屏幕常亮等页面功能，不能直接启用独立多开。**

## 安装

要求 SillyTavern 1.19.0 或更新版本，本版在 1.19.0 验证。复用酒馆已有的 Node.js 和依赖，无需另装 Python、数据库或额外服务。

### 1. 酒馆前端：在扩展安装框填写哪个网址？

打开酒馆的「扩展 → 安装扩展」（部分界面在「管理扩展」里），粘贴下面的网址并确认安装：

```text
https://github.com/sewtzxqd05-art/SillyTavern-Chat-Tabs
```

安装完成后刷新页面。前端可以选择仅当前账号安装或所有账号安装；下面的配套组件命令均适用。完整多开还需要完成第二步。

### 2. 安卓 Termux：下载并安装配套组件

先完成上面的前端安装。等待所有生成和保存结束，在启动酒馆的 Termux 窗口按 `Ctrl+C` 停止酒馆。编辑酒馆目录里的 `config.yaml`，把现有的 `enableServerPlugins` 改为：

```yaml
enableServerPlugins: true
```

保存后，在 Termux 粘贴并执行下面整段命令。默认酒馆位于 `$HOME/SillyTavern`；如果位置不同，只替换第一行的目录：

```sh
cd "$HOME/SillyTavern" &&
chat_tabs_installer="$(mktemp -d)" &&
git clone --depth 1 https://github.com/sewtzxqd05-art/SillyTavern-Chat-Tabs.git "$chat_tabs_installer" &&
sh "$chat_tabs_installer/install.sh" "$PWD" --backend-only
```

这段命令会把安装器下载到临时目录，再只安装配套组件。若提示 `git: command not found`，先执行 `pkg install git`，再重新执行上面整段命令。

看到 `Installed Chat Tabs 1.3.0 companion only` 后，按平时的方式重新启动酒馆，并刷新所有酒馆页面。从「魔术棒 → 多开聊天」进入，新建窗口和按项同步位于「2 · 多开与配套组件」。

### 完整安装包：可替代上面两步

- Windows：解压后双击「安装.cmd」，选择酒馆实际目录。
- 安卓 Termux / 自建 Linux 服务器：将包解压，在包目录运行 `sh ./install.sh "你的酒馆目录"`。
- 完整安装前，酒馆 `config.yaml` 需设为 `enableServerPlugins: true`。等生成和保存结束后，重启酒馆并刷新网页。

### 已安装前端：也可直接使用随附安装器

仓库根目录含扩展清单，可供扩展管理直接安装。然后在运行酒馆的设备上安装配套组件。无需重新下载另一个项目，可使用扩展里随附的安装脚本。

以默认酒馆路径与仓库目录名 `SillyTavern-Chat-Tabs` 为例，安卓 Termux / Linux：

```sh
cd "$HOME/SillyTavern"
sh ./public/scripts/extensions/third-party/SillyTavern-Chat-Tabs/install.sh "$PWD" --backend-only
```

按实际的酒馆和扩展目录修改路径；若通过“仅为当前用户安装”安装，扩展位于对应账号的 `data/<账号>/extensions/` 下。此命令只安装配套组件，保留已通过网页安装的扩展。

Windows 可在仓库目录运行：

```powershell
.\install.ps1 -TavernPath '你的酒馆目录' -BackendOnly
```

同样需要开启 `enableServerPlugins` 并重启酒馆。网页更新扩展后，如果新版本要求更新配套组件，请再次运行配套安装并重启。不要同时安装多个网页副本。

### 云酒馆

配套组件安装在实际运行酒馆的服务器上：自建服务器由管理员通过 SSH / 终端运行安装脚本；容器部署需由管理员将组件放进酒馆的 `plugins/chat-tabs`，并确保更新或重建容器后仍保留该目录与酒馆数据。仅拥有网页登录权限、不能管理服务器文件的用户，需要服务商协助安装。无需在访问网页的手机上安装 Termux。云部署暂未实测。

## 本版包含

- 独立聊天窗口、设置、API Hub 配置与密钥副本。
- 窗口改名、归档 / 恢复。
- **按项同步**：选择来源与目标，分别勾选美化、预设、API、角色卡更新；保留目标的聊天、当前角色与 user 人设。
- 可选静音音频与屏幕常亮。
- 可选后台生成与回复暂存；详见完整说明中的支持范围。
- **删除所有窗口**：主页面 → 魔术棒 → 多开聊天 →「多开与配套组件」→「删除所有窗口 · 卸载前清理」。包含已归档存档，需输入确认文字；生成、保存或窗口占用未结束时拒绝执行。永久删除无法恢复。

## 哪些共用、哪些独立

| 内容 | 当前行为 |
| --- | --- |
| 插件代码与安装文件 | 同一酒馆 / 账号可见范围内共用；安装、更新、卸载后其他窗口刷新会受影响 |
| 原生主题、CSS、插件启用列表和采用酒馆设置保存的插件配置 | 每个窗口分别保存；第三方插件自行使用共用浏览器存储或接口时需另行验证 |
| 角色卡、世界书、预设文件、头像图片 | 共用；修改资料后其他窗口可能需刷新或重新载入才能生效 |
| 当前预设选择、运行参数、API 配置、聊天和 user 人设 | 分别保存，不自动同步 |

## 按项同步

魔术棒 → 多开聊天 → 第二页 →「按项同步 · 保留目标窗口的聊天和人设」。先结束生成并关闭目标窗口，在主页面或另一个窗口操作：选择来源与目标、勾选项目、点击「同步所选项目」，成功后点击「打开目标窗口」。目标只能是已保存的独立窗口；主页面可作为来源。

| 勾选项 | 同步范围 |
| --- | --- |
| 美化 | 原生主题、CSS、背景、字体、聊天显示与布局；不复制第三方美化插件的私有配置或插件启用列表 |
| 预设 | 当前预设选择、提示词与生成参数；保持目标供应商、模型和密钥 |
| API | 原生对话供应商、模型、地址、对话密钥，以及 API Hub / 原生连接配置；未勾预设时保留目标当前预设 |
| 角色卡更新 | 核对共用角色卡资料，重新打开目标页时载入最新版本；不复制来源的聊天指针，不生成重复卡片 |

来源使用已保存的设置；来源为当前页面时会先保存。目标仍打开、生成中、保存 / 延迟备份未结束时拒绝同步。资料在核对期间变化时也会拒绝，请核对后重新操作。同步设置与密钥采用可恢复写入，意外退出后会在重新打开窗口前完成恢复。

同步预设或 API 后，API Hub 的「切换供应商时联动预设」默认关闭，避免重新打开时旧绑定覆盖刚同步的预设；可以自行重新开启。API 同步替换目标的对话连接与相应密钥副本，不复制搜索、翻译、绘图和 TTS 密钥，也不在页面返回密钥正文。第三方插件自行使用共用浏览器存储或自建接口的设置不在通用同步范围内。

不会自动合并主页面和独立窗口的聊天。

## 试用范围

已在 Windows、SillyTavern 1.19.0 验证；提供安卓 Termux 安装脚本与手机宽度页面适配，但未进行安卓真机锁屏 / 杀后台验证。云部署、iOS 与跨设备同时操作不在本版实测范围内。浏览器保活不能阻止系统强杀 Termux；后台生成也不能在酒馆进程被终止后继续执行。
