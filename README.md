# 酒馆多开 · Chat Tabs 1.6.0-beta.1

从「魔棒 → 多开助手」打开窗口列表。同一个角色可以开多条独立聊天，各窗口分别保存聊天记录、user 人设、预设参数和 API 连接。

这是 1.6 UI 改版测试版。当前版本的验收记录见 [REVIEW.md](REVIEW.md)。

## 一个列表管理窗口

主窗口固定在第一行；「你在这里」标记所在页面。其他窗口显示出字时长、字速、新回复或后台回复待处理。点「切换」返回已打开页面，点「打开」重新载入已保存窗口。浏览器限制自动聚焦时会提示手动切换标签页。

窗口的更多菜单提供关闭页面、行内改名、复制链接、同步设置和归档。关闭前确认设置与聊天保存成功；浏览器不能关闭标签页时改为轻量的已关闭页面。归档内容可恢复，也可单独永久删除。

悬浮提示只在生成、新回复或后台回复待处理时显示，本窗口完成后短暂保留耗时。可关闭或放在四个角；关闭后仍从多开助手查看状态。界面跟随酒馆主题，手机使用底部面板。

## 同步你选中的设置

设置 → 更多 → 同步设置，或者窗口的更多菜单 → 把设置同步到这个窗口。

| 项目 | 行为 |
|---|---|
| 美化 | 整套同步原生主题、CSS、背景和布局 |
| 预设 | 只同步所选 Chat Completion 预设；来源正在使用的预设带上工作副本中的修改 |
| API 连接 | 只合并选中的连接及对应密钥，保留目标独有的连接和密钥 |
| 目标改用 | 单独勾选后才切换目标的当前连接 |

来源可以是主窗口或独立窗口；目标只能是已关闭的独立窗口。多目标逐个执行并分别报告结果。目标聊天、人设、角色和名字不变。设置与密钥通过可恢复日志一起写入。

选了另一个预设文件时，目标下次打开会通过酒馆原生预设管理器应用。只有来源是本页、且选中来源正在使用的预设时，才可选择将工作副本另存回共用预设文件。

## 安装与更新

验证环境为 Windows、Node.js 24、SillyTavern 1.19.0。酒馆大版本升级后先查看终端是否出现 Chat Tabs 接口兼容错误。完整多开需要前端扩展和配套组件；复用酒馆已有 Node.js 与依赖，无需新增数据库或单独服务。

1. 等待生成与保存结束，停止酒馆。
2. 在 `config.yaml` 中设置 `enableServerPlugins: true`。
3. Windows 运行安装包中的 `安装.cmd`；Termux/Linux 在安装包目录执行 `sh ./install.sh "你的酒馆目录"`。
4. 重启酒馆，刷新所有页面。

安装器把旧插件目录移入酒馆的 `.chat-tabs-backups`，然后安装完整的新目录，避免已删除的旧文件残留。检测到其他位置的同名扩展时会停止，先保留一份前端安装再继续。安装器不改用户数据。

通过酒馆「扩展 → 安装扩展」可填写：

```text
https://github.com/sewtzxqd05-art/SillyTavern-Chat-Tabs
```

更新已有网页扩展后，仍需更新配套组件。Termux 可在停止酒馆后执行：

```sh
cd "$HOME/SillyTavern" &&
chat_tabs_installer="$(mktemp -d)" &&
git clone --depth 1 https://github.com/sewtzxqd05-art/SillyTavern-Chat-Tabs.git "$chat_tabs_installer" &&
sh "$chat_tabs_installer/install.sh" "$PWD" --backend-only
```

已有网页扩展时可在安装包目录只安装后端：

```powershell
.\install.ps1 -TavernPath '你的酒馆目录' -BackendOnly
```

```sh
sh ./install.sh "$HOME/SillyTavern" --backend-only
```

项目地址：[SillyTavern-Chat-Tabs](https://github.com/sewtzxqd05-art/SillyTavern-Chat-Tabs)。

## 记录与设置如何保存

角色卡、世界书、预设文件与头像图片共用；聊天、当前预设工作副本、API 连接、密钥副本和 user 人设分别保存。其他扩展自己使用的浏览器存储或独立接口，仍由其自身决定作用范围。

后台生成可在页面关闭后继续，支持普通单角色 Chat Completion 对话；支持来源为自定义兼容接口、OpenAI、OpenRouter、DeepSeek、xAI。群聊、重生成、续写、工具调用、多候选和自定义请求体使用普通生成。后台任务等待整段结果，不显示虚构字速。

系统通知需要主动授权；提示音需先点击页面。普通生成完成后在页面隐藏时通知，切回可见页面即清除普通新回复标记。后台回复必须写进聊天或丢弃才算处理。
