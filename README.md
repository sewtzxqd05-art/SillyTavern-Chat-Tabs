# 酒馆多开 · Chat Tabs

同一个角色开几条独立聊天，等回复时看看其他窗口的进度。

从 **魔棒 → 多开助手** 进入。窗口列表显示生成耗时、字速和新回复；悬浮提示可以关闭，界面跟随酒馆主题，手机使用底部面板。

**当前版本：1.6.0-beta.1（测试版）** · [下载安装包](https://github.com/sewtzxqd05-art/SillyTavern-Chat-Tabs/releases/tag/v1.6.0-beta.1) · [使用说明](使用说明.md) · [更新记录](CHANGELOG.md)

## 能做什么

- **独立聊天窗口**：分别保存聊天、user 人设、当前预设参数与 API 连接；关闭页面后可以重新打开。
- **查看生成进度**：显示本轮耗时、流式字速和新回复，切回窗口后清除普通回复的未读标记。
- **按需提醒**：单行悬浮提示、浏览器标题、提示音与系统通知，可分别开关。
- **选择同步**：同步原生美化、一个指定预设或选中的 API 连接及关联密钥，保留目标独有内容。
- **后台生成**：支持的对话可在页面关闭后继续生成，回来再写入聊天。
- **窗口管理**：改名、复制链接、保存后关闭、归档、恢复、单个永久删除。
- **新手练习**：四段可操作引导，使用演示数据。

角色卡、世界书、预设文件和头像共用；每个窗口的聊天与设置工作副本分开保存。

## 先看酒馆运行在哪里

这里的“网页扩展”指在酒馆里粘贴链接安装；“配套组件”指安装到运行酒馆的设备上、随酒馆一起启动的插件。不需要另开服务或数据库。

| 你的使用方式 | 安装位置 |
| --- | --- |
| Windows 电脑运行酒馆 | 在这台电脑安装完整包 |
| 安卓手机通过 Termux 运行酒馆 | 在这台手机的 Termux 安装 |
| 手机 / iPhone 访问自己的云端酒馆 | 配套组件装在云服务器，手机直接访问酒馆 |
| Docker 运行酒馆 | 由维护者安装到容器使用的持久化 `plugins` 目录，并启用配置；不要只装进会被重建清除的容器层 |
| 使用别人提供的托管酒馆，无法修改配置或安装组件 | 可以装网页扩展提供的页面功能；本版完整独立多开需要服务提供者安装配套组件 |
| iOS 上某个内置酒馆的 App | 取决于 App 是否支持原生扩展、配套插件与对应酒馆版本，未验证通用兼容 |

**本版完整多开需要网页扩展 + 配套组件。** 只安装网页扩展，可使用本页计时、标题提醒、提示音及浏览器允许的保活功能；不能创建本版的独立窗口，也不能让关闭后的页面继续生成。普通酒馆页面之间的独立状态列表尚未作为纯网页模式提供。

验证环境：SillyTavern **1.19.0**、Node.js 24、Windows。安卓、iOS、Linux 和 Docker 尚未完成实机验收；手机截图验证的是布局。

## 安装

### Windows：下载完整包

1. 在 [Release](https://github.com/sewtzxqd05-art/SillyTavern-Chat-Tabs/releases/tag/v1.6.0-beta.1) 下载 **`Chat-Tabs-1.6.0-beta.1.zip`** 并解压。
2. 等待生成和保存结束，停止酒馆。在酒馆 `config.yaml` 中将 `enableServerPlugins` 设为 `true`。
3. 双击解压目录里的 **安装.cmd**，选择包含 `server.js` 的酒馆目录。
4. 按平时方式启动酒馆，刷新页面，打开 **魔棒 → 多开助手**。

已经通过酒馆扩展管理器安装过前端时，请用下面的“只安装配套组件”，避免出现两份扩展。

### 安卓 Termux / Linux：一条命令下载并安装完整包

需要已有可运行的酒馆、`git` 和 Node.js。先停止酒馆，并在 `config.yaml` 设置：

```yaml
enableServerPlugins: true
```

以下命令按酒馆位于 `$HOME/SillyTavern` 编写；路径不同时修改开头的目录。命令固定下载本次发布版本，安装前会备份旧插件。

```sh
cd "$HOME/SillyTavern" && chat_tabs_installer="$(mktemp -d)" && git clone --depth 1 --branch v1.6.0-beta.1 https://github.com/sewtzxqd05-art/SillyTavern-Chat-Tabs.git "$chat_tabs_installer" && sh "$chat_tabs_installer/install.sh" "$PWD"
```

看到安装成功后，按平时方式重新启动酒馆，再刷新网页。命令不会自动停止酒馆、改配置或安装缺失依赖；Termux 缺少 git 时先执行 `pkg install git`。临时下载目录保留在系统临时目录中。

### 已通过链接安装网页扩展：只安装配套组件

酒馆 **扩展 → 安装扩展** 中填写：

```text
https://github.com/sewtzxqd05-art/SillyTavern-Chat-Tabs
```

随后在**运行酒馆的设备**上启用 `enableServerPlugins: true`、停止酒馆，再安装配套组件。Termux / Linux 使用：

```sh
cd "$HOME/SillyTavern" && chat_tabs_installer="$(mktemp -d)" && git clone --depth 1 --branch v1.6.0-beta.1 https://github.com/sewtzxqd05-art/SillyTavern-Chat-Tabs.git "$chat_tabs_installer" && sh "$chat_tabs_installer/install.sh" "$PWD" --backend-only
```

Windows 在完整包的解压目录打开 PowerShell，运行：

```powershell
.\install.ps1 -TavernPath '你的酒馆目录' -BackendOnly
```

重启酒馆后，在多开助手的设置页确认 **配套组件 1.6.0-beta.1 · 已连接**。前端和配套组件需使用匹配版本。

## 第一次使用

1. 点 **＋ 新窗口**，选角色和聊天起点；名称不填则使用角色名。
2. 点 **创建并打开**。API、美化、预设与 user 人设从来源窗口复制，之后分别修改。
3. 回到窗口列表，点 **切换 / 打开** 继续聊天。设置里可关闭悬浮提示。
4. 要统一某项设置，进入 **设置 → 更多 → 同步设置**，选择来源、已关闭的目标以及同步内容。

已有页面能否自动切换、关闭由浏览器决定；受限制时会提示手动切换，关闭失败时使用轻量的已关闭页面。

## 手机和云端的几个限制

- **建议用 HTTPS 访问云端酒馆**。普通局域网 HTTP 地址下，浏览器可能不提供通知、剪贴板、常亮等能力；本版独立窗口还使用安全上下文中的 UUID API，不能承诺远程 HTTP 可用。本机 `localhost` 的浏览器规则不同。
- **状态广播只在同一浏览器、同一站点地址内传递**。电脑和手机之间不共享普通前台生成的实时字速；配套组件提供的后台任务状态可重新读取。同一个独立窗口同时只允许一个页面写入。
- **页面后台运行不等于系统推送**。手机锁屏、切 App 或关闭浏览器后，页面可能暂停；本版没有 Web Push 服务，不能保证离线或锁屏时弹通知。iOS 的通知尤其不能仅凭“允许通知”判断可用。
- **后台任务依赖酒馆进程存活**。云端酒馆继续运行时，关手机页面不影响已接收的后台任务；Termux 被安卓杀掉、服务器重启或容器退出会中断任务。
- 反向代理需正常转发 `/api/plugins/chat-tabs/`、POST 请求和流式响应。子路径部署如 `/tavern/` 未验证，本版使用根路径链接，建议独立域名的根路径部署。

后台生成支持普通单角色 Chat Completion：自定义兼容接口、OpenAI、OpenRouter、DeepSeek、xAI。群聊、重生成、续写、工具调用、多候选、自定义请求体仍使用普通生成。后台回复整段返回，不显示虚构字速。

## 更新、备份与卸载

- **更新**：停止酒馆，更新网页扩展与配套组件，再重启并刷新。完整包安装器会备份并整体替换旧插件；检测到重复前端安装时会停止并提示。
- **回退**：旧代码保存在酒馆 `.chat-tabs-backups/<时间>/`。停止酒馆后恢复对应的前端与组件目录，再重启。不要用代码备份覆盖账户数据。
- **备份**：独立窗口保存在 `data/<账号>/chat-tabs/`，其中包含聊天与密钥副本。备份时妥善保管；本版未提供自己的导入导出向导。
- **卸载**：停止酒馆，移除对应扩展与 `plugins/chat-tabs`，再重启。保留窗口数据目录可供重新安装后继续；永久清理请先备份，再使用主窗口里的“删除所有窗口”。

搬聊天、导入导出和分步卸载向导计划在后续版本提供，当前尚未实现。
